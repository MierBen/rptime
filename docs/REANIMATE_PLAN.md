# MVP

### Что нужно для реанимиации проекта?

1. Стабилизация разработки
   1. Переезд в контейнеры/kubernetes
   2. Реализация pipeline сборки
   3. Поддержка всех базовых API (auth, task, team, ...) и исправления ошибок
   4. Поддержка нового Identity
   4. Переезд на MongoDB для хранения тасок
   5. Переезд на другой драйвер работы с БД (sqlx, ...)

### Требуемая базовая функциональность

1. Аутентификация/авторизация
2. Система тасок (расчет баллов, открытия, сдачи флагов)
3. Система связей тасок
4. Статистика
5. Динамическая система подгрузки тасок (из git и других мест)
6. Система администрирования
7. Базовый фронтенд (wasm?)
