# MVP

### Требуемая базовая функциональность

1. Аутентификация/авторизация
2. Система тасок (расчет баллов, открытия, сдачи флагов)
3. Система связей тасок
4. Статистика
5. Динамическая система подгрузки тасок (из git и других мест)
6. Система администрирования
7. Базовый фронтенд (wasm?)


### План

1. Настройка deploy для тестирования и разработки
2. Переделать бутстрапинг сервиса
3. Отрефакторить структуру проекта
4. Отрефачить модели данных
5. Сменить либу для работы с БД
